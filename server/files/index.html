Para navegar entre os arquivos servidos pelo servidor, basta inserir na barra de endereços do navegador o seguinte formato:

dominio:porta/caminho/do/arquivo.ext

Assim, o navegador solicitará diretamente o arquivo correspondente.

Exemplo:

localhost:5001/image.jpg

acessa o arquivo image.jpg.
